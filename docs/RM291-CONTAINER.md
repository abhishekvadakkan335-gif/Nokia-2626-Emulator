# RM-291 MCU parser validation
Local 06.80 sample was 9,012,647 bytes. Strict parsing consumed the entire file: 551 type-0x14 records, all header and payload checksums valid. Flash range 0x01000000–0x01896F84 exclusive; 9,006,924 payload bytes and 56-byte gap. Gap is filled with FF for inspection, not verified physical memory. The public DCT4 transform recovered RM-291, V 06.80, 16-11-07 and MIDP-2.0 / CLDC-1.1 strings. Byte patterns suggest big-endian Thumb; execution entry is not established. No sample or decoded proprietary data is distributed. Android implementation is not yet device tested. Supports the validated ordered A2 / 0x14 MCU subset only, rejects other records. Transform reference: https://github.com/sp00nznet/nokia-recomp/blob/main/recompiler/dct4decrypt.py (MIT); see included license.
